# <span class="lang-en lang-inline">About</span><span class="lang-zh lang-inline">关于我</span>

- a Ph.D. student (since Fall 2023) in the [Department of Electrical and Computer Engineering (ECE, formerly EEE)](https://ece.hku.hk/) at [The University of Hong Kong (HKU)](https://www.hku.hk/)<img src="images/hku-32x32.png" style="width: 1em;">

## <span class="lang-en lang-inline">🔬 Research Focus</span><span class="lang-zh lang-inline">🔬 研究方向</span>

<div class="lang-en lang-block" markdown="1">
My work spans four connected directions, from core **3D/4D reconstruction and generation** to **perception**, **embodied intelligence**, and **cross-disciplinary applications**.
</div>

<div class="lang-zh lang-block" markdown="1">
我的研究涵盖四个相互关联的方向，从核心的 **3D/4D 重建与生成**延伸至**场景感知**、**具身智能**及**交叉领域应用**。
</div>

<div class="research-focus-grid lang-en lang-block">
  <section class="research-focus-item">
    <h3>3D/4D Scene Reconstruction, Editing & Physical Simulation</h3>
    <p>Event-to-image reconstruction, NeRF, 3D Gaussian Splatting, editable neural scene representations, and video-based physical system identification for recovering and manipulating appearance, geometry, motion, and dynamics.</p>
    <p class="research-focus-links"><strong>Representative works:</strong> <a href="https://ieeexplore.ieee.org/document/11733892">ERF-GS</a> · <a href="https://arxiv.org/abs/2608.00694">E2Pano</a> · <a href="https://arxiv.org/abs/2507.23704">4DGS</a> · <a href="https://arxiv.org/abs/2405.07306">Editable NeRF</a> · <a href="https://arxiv.org/abs/2508.01112">MASIV</a></p>
  </section>
  <section class="research-focus-item">
    <h3>Structured Generation & Neural Network-driven Rendering</h3>
    <p>Structured scene and garment generation, path-traced image synthesis, and event-camera simulation for controllable, simulation-ready worlds.</p>
    <p class="research-focus-links"><strong>Representative works:</strong> <a href="https://arxiv.org/abs/2610.16146">Unravel</a> · <a href="https://lagrangeli.github.io/PatternGSL/">PatternGSL</a> · <a href="https://arxiv.org/abs/2608.07012">Scenix</a> · <a href="https://lagrangeli.github.io/EventTracer-simulator/">EventTracer</a></p>
  </section>
  <section class="research-focus-item">
    <h3>Video Understanding, Scene Perception & Embodied AI</h3>
    <p>Action recognition, anomaly detection, panoramic segmentation, vision-language-action reasoning, and embodied navigation for understanding and interacting with dynamic environments.</p>
    <p class="research-focus-links"><strong>Representative works:</strong> <a href="https://proceedings.neurips.cc/paper_files/paper/2022/file/5820ad65b1c27411417ae8b59433e580-Paper-Conference.pdf">Temporal Attention</a> · <a href="https://arxiv.org/abs/2607.18142">O-VAD</a> · <a href="https://lutao2021.github.io/SAP_Page/">SAP</a> · <a href="https://arxiv.org/abs/2605.09869">ConsistNav</a></p>
  </section>
  <section class="research-focus-item">
    <h3>Computational Imaging, Biomedical AI & Engineering Systems</h3>
    <p>Neural holography, foundation models for biomedical imaging, AR-assisted healthcare, recommender systems, and wireless communication.</p>
    <p class="research-focus-links"><strong>Representative works:</strong> <a href="https://opg.optica.org/ol/abstract.cfm?uri=ol-50-4-1188">3D-HoloNet</a> · <a href="https://www.arxiv.org/abs/2407.06833">CryoSAM</a> · <a href="https://doi.org/10.1002/jsid.70061">AR-assisted surgery</a></p>
  </section>
</div>

<div class="research-focus-grid lang-zh lang-block">
  <section class="research-focus-item">
    <h3>3D/4D 场景重建、编辑和物理仿真</h3>
    <p>研究事件到图像重建、NeRF、3D Gaussian Splatting、可编辑神经场景表示及基于视频的物理系统辨识，用于恢复与操控场景外观、几何、运动和动力学属性。</p>
    <p class="research-focus-links"><strong>代表性工作：</strong><a href="https://ieeexplore.ieee.org/document/11733892">ERF-GS</a> · <a href="https://arxiv.org/abs/2608.00694">E2Pano</a> · <a href="https://arxiv.org/abs/2507.23704">4DGS</a> · <a href="https://arxiv.org/abs/2405.07306">Editable NeRF</a> · <a href="https://arxiv.org/abs/2508.01112">MASIV</a></p>
  </section>
  <section class="research-focus-item">
    <h3>结构化生成与神经网络驱动的渲染</h3>
    <p>研究结构化场景与三维服装生成、路径追踪图像合成及事件相机仿真，构建可控且可仿真的三维世界。</p>
    <p class="research-focus-links"><strong>代表性工作：</strong><a href="https://arxiv.org/abs/2610.16146">Unravel</a> · <a href="https://lagrangeli.github.io/PatternGSL/">PatternGSL</a> · <a href="https://arxiv.org/abs/2608.07012">Scenix</a> · <a href="https://lagrangeli.github.io/EventTracer-simulator/">EventTracer</a></p>
  </section>
  <section class="research-focus-item">
    <h3>视频理解、场景感知与具身智能</h3>
    <p>研究动作识别、异常检测、全景分割、视觉-语言-动作推理与具身导航，使智能体理解动态环境并与之交互。</p>
    <p class="research-focus-links"><strong>代表性工作：</strong><a href="https://proceedings.neurips.cc/paper_files/paper/2022/file/5820ad65b1c27411417ae8b59433e580-Paper-Conference.pdf">Temporal Attention</a> · <a href="https://arxiv.org/abs/2607.18142">O-VAD</a> · <a href="https://lutao2021.github.io/SAP_Page/">SAP</a> · <a href="https://arxiv.org/abs/2605.09869">ConsistNav</a></p>
  </section>
  <section class="research-focus-item">
    <h3>计算成像、生物医学智能与工程系统</h3>
    <p>探索神经全息、生物医学影像基础模型、增强现实辅助医疗、推荐系统与无线通信。</p>
    <p class="research-focus-links"><strong>代表性工作：</strong><a href="https://opg.optica.org/ol/abstract.cfm?uri=ol-50-4-1188">3D-HoloNet</a> · <a href="https://www.arxiv.org/abs/2407.06833">CryoSAM</a> · <a href="https://doi.org/10.1002/jsid.70061">增强现实辅助手术</a></p>
  </section>
</div>
